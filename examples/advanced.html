The advanced view

The window as a whole screen: past conversations on the left, the chat in the middle, the app's own page on the right. Serve this folder from any static server (the page on the right must come from the same address as this one), then open the view.

Try it

Ask about October's occupancy: the assistant says what it is doing, opens the season report on the right by itself and writes its answer. Press Stop while it writes. Star a conversation, search the list, make the window narrow to see the laptop and phone layouts.

What a host passes

createAiChatWidget({
  // …the small window's options, and:
  getAdvancedUrl: (path) => appUrl(path ?? currentPath),   // the page on the right
  listThreads, loadThread,                                   // the list on the left
  advancedLogo: { src: "/logo.svg", srcDark: "/logo-dark.svg", symbol: "/mark.svg", alt: "Acme Hotel" },
  renderAdvancedFooter: (host) => drawAccountMenu(host),    // bottom-left corner
});

A host with no app to frame passes advancedView: true instead of getAdvancedUrl: the list and the chat, and a right side that opens only for a result. Without starThread the star is kept in this browser; the "new answer" dot always is.
